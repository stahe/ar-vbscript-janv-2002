# مقدمة إلى VBScript

يحتوي هذا المستودع على شفرة المصدر والوثائق الخاصة بالدورة التدريبية التمهيدية حول VBScript.

🔗 **[عرض الدورة التدريبية عبر الإنترنت](https://stahe.github.io/ar-vbscript-janv-2002/)**

## نظرة عامة

VBScript هي لغة برمجة نصية لنظام Windows يمكن استخدامها في مجالات متنوعة. وهي سهلة التعلم وتُعد بوابة الدخول إلى Visual Basic for Windows، التي تنبثق منها مباشرةً.

على الرغم من أن VBScript ليست لغة موجهة للكائنات (فمفهوم الوراثة، على سبيل المثال، غير موجود)، إلا أنها تتميز ببعض الخصائص الموجهة للكائنات. تكمن قوتها في قدرتها على استخدام الكائنات التي يوفرها حاوية التنفيذ الخاصة بها، بالإضافة إلى مكونات ActiveX المتوفرة على جهاز الكمبيوتر الذي يعمل بنظام Windows. وهذا يتيح لها منافسة لغات أكثر ثراءً من حيث الوظائف في البداية، مثل Perl أو JavaScript أو Python.

## سياقات التنفيذ

يمكن تنفيذ VBScript في بيئات متنوعة:

**Windows Scripting Host (WSH)**: للاستخدام المباشر في Windows، خاصة لكتابة نصوص برمجية لإدارة النظام. عادةً ما يكون WSH مضمنًا بشكل قياسي في نظام التشغيل Windows.



**Internet Explorer**: يُستخدم داخل صفحات HTML، ويوفر تفاعلية لا يمكن الحصول عليها باستخدام HTML وحده.


**Internet Information Server (IIS) / Personal Web Server (PWS)**: يُستخدم VBScript للبرمجة على جانب الخادم عبر تقنية ASP (Active Server Pages) من Microsoft.




## الارتباط بـ Visual Basic و VBA

نظرًا لأن VBScript مشتق من Visual Basic، فإنه يُعد مقدمة ممتازة لهذه اللغة المستخدمة على نطاق واسع في نظام Windows. بالإضافة إلى ذلك، فإنه يُعد المستخدمين لـ **VBA (Visual Basic for Applications)**، وهي النسخة المستخدمة في مجموعة Microsoft Office (خاصة Excel).

وبالتالي، يُعد VBScript نقطة انطلاق متميزة لتطوير تطبيقات Windows.
